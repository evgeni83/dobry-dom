# Гостевой дом «Добрый Дом» — лендинг

Современный одностраничный сайт (лендинг) для гостевого дома **«Добрый Дом»** в Ейске.
Свёрстан на чистом HTML + CSS + JavaScript — без сборки и зависимостей. Открывается
двойным щелчком по `index.html` и без проблем размещается на любом статическом хостинге
(GitHub Pages, Netlify, обычный хостинг и т. д.).

2. **Hero** — заголовок, рейтинг, чипы удобств, кнопки, «мозаика» из фото.
3. **Цифры** — 5,0 · 102 отзыва · 469 м до моря · 2018 · 24/7.
4. **О доме** — текст + преимущества.
5. **Удобства** — 6 карточек с иконками.
6. **Цены** — диапазон стоимости и что входит в проживание.
7. **Фотогалерея** — masonry-сетка с лайтбоксом.
8. **Расположение** — встроенная Яндекс Карта, адрес, остановки, кнопка «Вызвать такси».
9. **Отзывы** — оценка и ссылки на Яндекс Карты / Путешествия.
10. **Бронирование** — контакты и форма, которая формирует готовое сообщение в WhatsApp.
11. **Подвал** и **мобильная панель действий** (Позвонить · WhatsApp · Забронировать).

## Как посмотреть

Просто откройте `index.html` в браузере. Для корректной работы карты и шрифтов нужен интернет.

Локальный сервер (необязательно):

```bash
python -m http.server 8000
# затем http://localhost:8000
```

## Что легко поменять

| Что | Где |
|---|---|
| Телефоны, WhatsApp | `index.html` (ссылки `tel:` и `wa.me/…`), `js/main.js` → константа `WHATSAPP` |
| Цены, тексты, преимущества | `index.html` |
| Цвета, радиусы, тени, шрифты | `css/styles.css` → блок `:root` |
| Фотографии | замените файлы в `assets/images/` (сохранив имена) |
| Координаты карты | `index.html` → `iframe` Яндекс Карты и ссылки «Как добраться» |

## Анимации при прокрутке (GSAP + ScrollTrigger)

Библиотеки подключены локально (`js/vendor/gsap.min.js`, `js/vendor/ScrollTrigger.min.js`, версия 3.12.5),
поэтому интернет для анимаций не нужен. Всё инициализируется в конце `js/main.js` в блоке `if (hasGSAP)`.

| Эффект | Что делает | Где смотреть |
|---|---|---|
| **Scrubbing** | анимация привязана к позиции скролла: вниз — вперёд, вверх — назад (`scrub: 1`) | hero (`.hero__content`, `.hero__gallery`, `.hero__bg`), фото в «О доме» |
| **Pinning** | блок фото «прилипает» ровно по центру экрана, текст прокручивается мимо (`pin: true`) | `.about__media` (только от 1081 px) |
| **Smooth reveals** | мягкое появление: `opacity 0 → 1` + сдвиг `y: 30 → 0`, с каскадом для сеток | все элементы с атрибутом `data-reveal` |
| **Счётчики** | цифры «набегают» при появлении | `.stat__num` |

Как это устроено:

- Разметка **не переписана** — используются уже существующие классы и атрибут `data-reveal`.
- Анимируются только `opacity` и `transform`, поэтому **нет layout shift** (CLS).
- Пока грузится страница, элементы скрыты через CSS; GSAP проявляет их сам. Если GSAP не загрузится,
  включается резервный `IntersectionObserver` (в `main.js` есть ветка `!hasGSAP`).
- При `prefers-reduced-motion: reduce` GSAP-анимации не запускаются, контент показывается сразу.
- Пиннинг на экранах < 1081 px отключён (одна колонка) — там работают только reveal-анимации.

Хотите подключить GSAP с CDN вместо локальных файлов — замените два тега `<script>` в `index.html`:

```html
<script src="https://cdn.jsdelivr.net/npm/gsap@3.12.5/dist/gsap.min.js" defer></script>
<script src="https://cdn.jsdelivr.net/npm/gsap@3.12.5/dist/ScrollTrigger.min.js" defer></script>
```

## Технические детали

- Адаптив от 360 px до широких экранов.
- Доступность: семантические теги, `aria`-атрибуты, фокус-стили, лайтбокс с клавиатурой
  (`Esc`, `←`, `→`) и поддержкой свайпов.
- Анимации при прокрутке на **GSAP + ScrollTrigger** (scrubbing, pinning, reveals); если GSAP недоступен —
  резервный `IntersectionObserver`. При `prefers-reduced-motion` анимации отключаются.
- SEO: `title`/`description`, Open Graph, микроразметка `LodgingBusiness` (JSON-LD).
- Форма бронирования не требует бэкенда: собирает заявку и открывает WhatsApp.
